# ملفات الظل — الرحلة الأخيرة

أول نموذج قابل للعب للعبة تحقيق عربية 2D.

## الفكرة الحالية
- إنشاء هوية المحقق واختيار اسمه.
- بداية سينمائية داخل منزل المحقق.
- اتصال ياسر النجار.
- الدعوة إلى الرحلة والزفاف.
- رحلة القطار.
- توقف القطار بسبب الثلوج.
- اكتشاف الجريمة.
- نظام ذاكرة يحفظ الأحداث والمعلومات تلقائيًا.

## التطوير التالي
سنحوّل النموذج إلى لعبة تحقيق كاملة: شخصيات قابلة للاستجواب، أدلة، أقوال، لوحة ربط، حرية ترتيب التحقيق، حالات فشل ونجاح، وحفظ تقدّم.
